# 英語読解サポートの追加辞書

拡張機能の「辞書の設定」に[配布情報JSON](https://github.com/yun-xd5/reading-assist-dictionary/releases/latest/download/dictionary-release.json)のURLを入力して取得できます。

## データの出典とライセンス

- 日本語訳と品詞は、James William Breen と Electronic Dictionary Research and Development Group (EDRDG) の [JMdict](https://www.edrdg.org/jmdict/j_jmdict.html) に基づきます。
- 英語の頻度は Robyn Speer の [wordfreq](https://github.com/rspeer/wordfreq/blob/master/NOTICE.md) に基づきます。
- 配布データは [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) です。JMdictから英語で逆引きできる候補を抽出し、頻度に基づく難易度を加えています。
